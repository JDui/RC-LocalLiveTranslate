# 07 — 测试计划、Benchmark 与质量门禁

**以下全是工程目标，非已测数据。**

| 指标 | 初期目标/验收设想 | 计量起点 |
| --- | --- | --- |
| 首条临时字幕 | P50 ≤ 2 秒 | 语音起始到可见 |
| 最终 ASR | P90 ≤ 1.5 秒 | VAD 确定句末到稳定字幕 |
| 英译中 | P90 ≤ 1 秒 | 稳定英文文本到中文 |
| 日译中 | P90 ≤ 2 秒 | 稳定日语文本到 pivot 中文 |
| 说话人初步标签 | 争取 1–3 秒有效语音，未知可继续 | 当前人开口到初步归属 |
| 长时间运行 | 至少飞行模式 30 分钟，随后 60 分钟 | 不崩溃、不持续积压、无明显内存泄漏 |

P50/P90 需有样本数、设备及分布，未达到时以录音连续性优先，透明报告结果。

## 真机矩阵

- Android 9、13、14、15、16；有条件再加入 Android 17 测试。
- ARM64 旗舰 8 GB/12 GB、低配置对照；记录 SoC、系统、散热、内存与电量。
- 场景：中/英/日单语、跨语种同一人 zh→ja→en→zh、A-B-A、2-4 人、插话、重叠语音、噪声/餐厅、短句、长句。
- 行为：飞行模式、锁屏、恢复前台、后台权限限制、麦克风被占用、蓝牙耳机切换、导入坏模型和满存储。

## 准确性

中文 CER、英语 WER、日文 CER（统一正规化）；语段级 LID 混淆矩阵、unknown rate；speaker DER/JER 与跨语言 ID 保持率；译文人工语义校验、实体名/敬语案例。尤其同时讲话单独标示困难，不以静默丢句掩盖问题。

## 性能记录与自动化

每轮记录模型 tag/SHA、ASR RTF、译文耗时、Speaker embedding ms、队列积压、丢帧、PSS/RSS、热机、电池、是否加载全部模型。输出结构化 JSON/CSV；测试音频仅限许可允许的样本，不提交私人录音。

建立单元测试、Gradle assembleDebug、Compose UI test、Android 仪器测试、真机 Macrobenchmark。**构建成功 ≠ 真机 AI 性能验证成功**，没有测过必须标 NOT TESTED。
