Android 9+ / ARM64，versionCode 303，显示名「RC翻译魔芋」。沿用原签名，可覆盖旧公开版本。GitHub Release 不标记 prerelease，仅附携带四模型的 `RC-LocalLiveTranslate-0.3.3-arm64-bundled.apk`（686.3 MiB）；无模型版（77.4 MiB）同时构建并保存在本地。

- 完善无字幕记录、无诊断报告、禁用操作的解释；删除使用危险色并说明不可恢复，空白重命名不可保存，城市重复保存禁用。
- 保留三项导航、设置中的模型 / 运行子页、两次独立左滑删除、离线推理和用户主动城市查询。声纹首次尝试以 0.8 秒音频为门槛，不是实测端到端延迟。
- README 重新拍摄本版签名 APK 的手机 / 展开尺寸截图；演示字幕和文件安装状态均明确标注。

## 安装与模型

公开整合 APK 内置 SenseVoice Small INT8 2024、Silero VAD、CAM++、Hy-MT2 1.8B STQ。首次启动通过生产导入器安装和校验缺失模型，已有模型不覆盖；至少预留 2 GiB 可用空间。无模型版可经本地 ZIP 导入或主动下载权重。语音识别、翻译及声纹完全在本地运行，无录音 / 字幕上传或遥测。

主动获取城市仍使用前台大致位置及系统 Geocoder，系统服务可能联网并向其服务商发送坐标；应用只保存城市名，不自动查询，语音推理不依赖它。
