# 0.1.0-prealpha.5 — 五语选择与牛皮纸主题

Android 9+ / ARM64；versionCode 5。公开 Release 只附不携带模型的签名 APK：`RC-LocalLiveTranslate-0.1.0-prealpha.5-arm64.apk`。沿用项目签名，可覆盖旧公开版本。模型可在应用内主动下载或通过本地 ZIP 离线导入，准备后识别和翻译在手机本地运行。

## 更新

- 接通中 / 英 / 日 / 韩 / 粤语言标签及翻译目标；沿用固定 SenseVoice Small INT8 2024 与 Hy-MT2 1.8B STQ 权重，无需新增模型。
- 两个语言选择框：默认自动识别 → 中文；可选择任意两种不同语言双向互译。具体语言对之外保留原文，未知标签不猜测；会话期间锁定选择，兼容旧设置及历史字幕。
- 自动模式按 CPU 核数设置翻译生成最多 4 线程、预填充最多 6 线程；省电和中度热压力最多 2 / 2，低核数设备继续限幅。下一句前更新并复用 context，严重及临界压力保护保留。尚无真机加速结论。
- 纯色牛皮纸浅 / 深主题、小圆角与统一缩进；应用显示名为「阿西牌翻译魔芋」，使用满幅魔芋自适应图标。
- 打包脚本接受整合版版本参数，并在签名前拒绝将含模型 APK 当作无模型发行包。

## 安装和制品

公开 APK 为 81,082,199 bytes（77.3 MiB），不含模型。完整原始权重约 697 MiB，至少预留 2 GiB 可用空间。应用内下载只取缺项，有进度、取消和失败重试；访问 GitHub / Hugging Face，无后台续传。也可使用离线 ZIP。无云推理、录音 / 字幕上传或遥测。

同版本另构建本地整合版 `RC-LocalLiveTranslate-0.1.0-prealpha.5-arm64-bundled.apk`，719,546,520 bytes（686.2 MiB），内含 SenseVoice、Silero VAD、CAM++ 和 Hy-MT2 四个模型 ZIP，首次启动由生产导入器安装缺失模型，已有模型保留。整合版仅保存在本地忽略目录 `.tools/releases/`，不附到 GitHub Release；权重、签名材料及 APK 不提交 Git。

## 验证边界

197 项主机回归通过，0 failures / errors / skipped。两种 Release 构建成功；无模型版 lint 0 错误 / 3 警告，整合版 0 错误 / 16 警告，包含依赖更新、Kapt 和注释提示。两包签名、版本 / ABI / 不可调试属性、必需 JNI（含线程配置入口）、五个 ARM64 ELF / APK ZIP 16 KB 对齐通过。无模型版没有权重；从整合 APK 提取的四个 ZIP 通过固定版本、大小、摘要与来源清单校验。详情见 [11_VALIDATION](11_VALIDATION.md)。README 模拟器截图仍属于 prealpha.4，未展示本版外观。
