# 01 — 产品范围与验收标准

**状态：需求确定，精度和性能未验收。**

## 核心需求

| ID | 要求 | 验收方式 |
| --- | --- | --- |
| R1 | 飞行模式下运行 | 麦克风、ASR、LID、声纹分离、翻译全部可用 |
| R2 | 自动中/英/日识别 | 不手工切语言；短句可输出 unknown |
| R3 | 自动分辨说话人 | A/B/A 能复用 A；跨语言仍能匹配 A |
| R4 | 文字实时展示 | 原文及简体中文译文；无需 TTS |
| R5 | 不假装百分百准确 | 支持未知说话人、临时文本与历史修正 |
| R6 | 清晰录音控制 | 开始、暂停、停止、前台服务通知与停止入口 |
| R7 | 完全离线模型 | 外部模型文件导入、校验、版本查询和删除 |
| R8 | 数据可管理 | 默认不保存原始 PCM；文本记录本地可关闭、删除、导出 |

## 首版范围

首版输入来自麦克风；非中文语音翻译到简体中文，中文仅展示原文。对话中的同一人可以切换语言。实时字幕卡片包含人、源语言、时间、原文、译文与稳定状态。允许异步更正文本和说话人归属。

## 明确不做

不做 TTS、语音克隆、识别真实个人身份、远程服务器、手机间同步；不承诺同时分离重叠讲话的完整语义；Android 内部音频、悬浮窗、Speaker 手动命名、批量导出可在下一阶段加入。

## 非功能性

高优先级保证录音流连续、低内存有可见降级、网络关闭可运行、可终止后台任务。用户须明确知道录音状态。模型加载失败不得导致无限崩溃/重启。性能数字见 07_QUALITY，仅为待测目标。
