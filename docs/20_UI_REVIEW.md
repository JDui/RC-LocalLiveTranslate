# UI 审查与修正

范围：本地签名四模型整合版；最小 API35 模拟器，360×640 dp，2核/2048 MiB。采用 Product Design audit 流程，本轮重新截图并检查，没有拿旧截图当证据。

| 审查步骤 | 原问题 / 状态 | 修正 |
| --- | --- | --- |
| 首页 | 顶部和底部占据过多高度 | 合并语言/输入行，隐藏就绪模型重复提示，空闲时去掉假音量条 |
| 语言选择 | 不显示双向含义和当前选项 | 双向箭头、勾选标记与 selected 语义 |
| 演示与跟随 | 约15秒仍停在首条；字幕时间超过总长 | 仅用户滚动改变跟随状态，跟到末条底部；演示时间统一2.6秒/条 |
| 模型页 | 版本、许可、URL占据列表；小模型显示零大小 | 进入详情弹窗，保留状态和大小；小于1MiB使用KiB |
| 记录列表/详情 | 预置记录、原译文与返回/导出入口可见 | 沿用原操作；本次未执行系统SAF导出 |
| 设置 | 常用设置可见、可滚动 | 保留原设置布局 |
| 200%系统字体 | 字幕区域消失，底栏强制两行 | 输入菜单与短导航标题释放空间，保留完整图标语义名称 |
