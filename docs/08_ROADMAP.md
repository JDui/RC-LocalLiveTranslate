# 08 — 实施路线和 Definition of Done

| Milestone | 工作 | 结束条件 |
| --- | --- | --- |
| M0 文档初始化 | 架构/技术栈/GUI/模型/质量/合规 | 文档完整，风险与未实现部分明确 |
| M1 Android 项目骨架 | Kotlin、Compose、主题、三页、Service、权限、Gradle CI | 真机安装、录音启停/权限流程可靠 |
| M2 ASR+LID | AudioRecord、VAD、SenseVoice、字幕状态 | 飞行模式中英日原文自动识别 |
| M3 离线翻译 | Foxlet、en→zh、ja→en→zh、模型导入 | 飞行模式全语言路由和哈希保护 |
| M4 在线声纹 | Speaker embeddings、聚类、unknown、异步修订 | A-B-A / 同人跨语言回归 |
| M5 使用体验 | 历史记录、横屏、可访问性、导出、调试 | Compose UI test + 权限 UX |
| M6 性能发行 | 30–60 min 热机、内存、Battery、许可、NOTICE、APK | 真机报告 + 可重现构建 |

### 次序与约束

0.1.0 已实现 M1 工程、M2–M4 原生调用及有界实时管线，并提前完成部分 M5 GUI、折叠屏、记录及导出。当前已编译原生库和主机回归，尚未用实际模型在 Android 上运行，因此 M1–M4 的设备、准确率与离线验收不能标记完成。模型 ZIP 导入校验、合成后端管线测试及 APK 16 KB 对齐均不等同真机推理成功。详见 10_DEVELOPMENT 与 11_VALIDATION。

音频前端已加入采样率回退、独立 DSP 有界队列、累计样本时钟、输入切换边界及 DEAD_OBJECT 有限恢复；主机验证包含两分钟 44.1 kHz 长度、波形及过载回归。热与低内存分档、可选资源延迟加载 / 空闲释放、自动 / 省电模式和临界压力取消已实现，但阈值与真实资源行为未经过设备校准。有界性能采样与 JSON / CSV 导出工具已实现，翻译魔芋自适应图标已接入；这些不替代蓝牙 / USB / 权限撤销实机测试，也不替代 M6 的 30–60 分钟原生多模型热机。speaker 历史标签合并与近期证据拆分已实现；真实权重许可审核、真人效果和实测性能报告仍未完成。

用户授权最终提交 / 推送并发布 prealpha 测试版。发布不将尚缺设备的项目冒记为验收完成；测试版必须列明权重不捆绑、ARM64 限制及实机证据缺口。发行审查发现官方 sherpa Android v1.13.8 默认构建开启 TTS，带来本应用未使用的额外组件和许可边界；已改为固定源码关闭 TTS / 离线 diarization 的构建，保留嵌入抽取，并补全原生依赖许可与来源。APK 已检查无相应禁用导出，下一步为最终源码 / 发行候选审阅、签名和 prealpha 交付，仍不代表完整合规或设备验收完成。

2026-10-12 最终源码候选的 Debug / Release、单元测试、两类 lint 和设备测试 APK 构建通过；142 项普通主机测试无失败。首个非调试 ARM64 prealpha 已完成本地签名及 APK 本体检查，发行入口与安装限制见 [15_PREALPHA](15_PREALPHA.md)。软件候选交付不关闭 M1–M6 的实机门禁，尤其不能代替飞行模式推理、真实声纹和 OEM 折叠连续性。

同日 prealpha.2 修复延迟加载记录时的阅读恢复，补齐 tabletop 模型 / 记录页和生产 Activity 重建回归。146 项普通主机测试、完整本地构建及对应远程 CI 通过，第二版已公开且保留第一版。升级与证据见 [16_PREALPHA_2](16_PREALPHA_2.md)；实际杀进程恢复、OEM 开合与模型 / 音频门禁不因此关闭。

M1→M2→M3 构成最短可用产品；M4 是最难的算法模块，不与录音线程捆绑。通过可替换接口集成，必要时先发无声纹功能的内测包，但 UI 显示 Speaker unknown 不伪造标签。

五套实际模型基线包已在本地准备，生产导入器和租约通过真实文件主机测试。Windows x64 三语 TTS 检查发现 2025 粤语候选 auto 全部标 yue，默认评测基线改为同条件通过的 2024 原版。实际 host 模型执行不等于 M2–M4 Android / 真人验收；AndroidJNI、翻译结果、声纹同人跨语言和 M6 热机仍缺设备证据。详情见 14_MODEL_PREPARATION 与 ADR-0003。

折叠适配质量追加参照小红书级别的成熟体验，不能仅满足铰链避让。已推进四页功能双栏、展开平屏空间利用、紧凑详情返回、记录选中与滚动保存，以及大字体独立滚动。主机姿态 / 窗口调整和可保存状态恢复可验证软件路径，但 OEM 真实开合、输入法、动画、录音连续性仍未验收，不能宣布达到该质量目标。

首个代码提交建议：可编译 Android Studio 工程、Version Catalog、Compose Live/Models/Settings 三页面、权限流程和假字幕数据状态，配置 assembleDebug CI；再接入 AudioRecord。未创建源码前不声称这些工作完成。默认直接在 main 工作且推送前仔细审阅。
