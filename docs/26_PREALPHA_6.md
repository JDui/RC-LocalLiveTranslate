# 0.1.0-prealpha.6 — 声纹提前调度与设置整理

Android 9+ / ARM64；versionCode 6，显示名「RC翻译魔芋」。公开 Release 仅附不携带模型的 `RC-LocalLiveTranslate-0.1.0-prealpha.6-arm64.apk`（77.4 MiB），沿用项目签名，可覆盖旧公开版本。

## 更新

- 声纹与 ASR 独立调度：VAD 检出后以约 0.8 秒音频为首次尝试门槛，不等待句末；未决证据最多每秒重试，保留容量 4 队列、原生就绪和歧义判断。门槛不是实测延迟，同一句中途换人、重叠语音及真人准确率仍待验证。
- Speaker 标签使用稳定独立色相，原文 / 译文带对应淡色，并保留文字标签；主机测试覆盖浅深背景下的配色对比度。
- 导航调整为即时字幕 / 对话记录 / 设置。离线模型为设置首项，运行与诊断为设置子页；同一窗口下 Dock 跨页保持固定，展开屏设置入口固定在侧栏底部。
- 记录第一次左滑展开删除区，再次独立左滑删除；保留按钮确认路径及向右收起。两个语言菜单相互排除另一框已选语言，选项文本与箭头紧凑居中。
- 设置可主动「获取当地城市」，只申请前台大致位置并使用手机系统 Geocoder；失败可手动填写，晚到结果保留手动修改。系统服务可能联网并向服务商传送坐标，应用只保存城市名，不保存坐标；不会在启动或录音时自动查询。离线语音推理不依赖定位服务。
- README 替换为本版签名 APK 的原始模拟器截图，覆盖 1080×2520 竖屏和 1800×1920 展开尺寸的字幕、记录、模型、设置及运行诊断。字幕 / 记录明确为固定演示，展开尺寸不代表实际铰链或 OEM 验收。

## 模型与安装

公开 APK 不含权重，从「设置 → 离线模型」主动下载缺失项或通过 ZIP 离线导入。沿用 SenseVoice Small INT8 2024、Silero VAD、CAM++ 与 Hy-MT2 1.8B STQ 固定模型。全部原始权重约 697 MiB，至少预留 2 GiB 空间；下载源为 GitHub / Hugging Face，无后台续传。无云识别 / 翻译、录音 / 字幕上传或遥测。

同版本构建四模型整合版 `RC-LocalLiveTranslate-0.1.0-prealpha.6-arm64-bundled.apk`（686.3 MiB），只保存在本地 `.tools/releases/`，不作为公开附件。模型、APK、签名材料与本地测试日志不提交 Git。
