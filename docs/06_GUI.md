# 06 — GUI 技术栈与交互规格

**决定：Kotlin + Jetpack Compose + Material 3。** Navigation Compose 管理页面，ViewModel/StateFlow 管理完整状态，状态不可变，所有耗时操作经 Repository/UseCase 到 Service/Native 层。

## 核心页面

| 页面 | 操作与内容 |
| --- | --- |
| Live | 开始/暂停/停止、拾音状态、实时字幕列表、Speaker 图例、正在处理的提示 |
| Settings → 离线模型（首项） | 模型完整性、语言、版本、大小、许可、SHA 校验、本地导入、删除；不再占用独立导航 tab |
| Sessions | 本地历史、重命名、SRT/JSON/纯文本导出（后续） |
| Settings | 双语/仅中文、字号、深浅主题、性能档位、保留记录开关、语言路由 |
| Settings → 运行与诊断 | 合并原“当前运行”和“运行诊断”，显示队列、推理耗时、PSS、过热状态及诊断报告导出，不记录 PCM |

## 字幕卡片契约

每条字幕保留以下信息：Speaker A/B/C/未知、稳定颜色+文字标签、源语种 ZH/EN/JA/KO/YUE/Unknown、原文、所选目标语言译文（同语言不重复）、相对时间；识别中、修订、翻译中或不可用时显示状态，已完成 final 不重复占行显示“已确认”。支持临时文本渐进变成 final；修正只局部更新，避免整表跳动。只有用户位于滚动列表底部时自动滚动；向上读历史时禁止强制跳回。

说话人配色不能仅靠颜色识别，应满足正常文字 4.5:1 对比，文字标签及 TalkBack 描述必须完整；同一人跨语言颜色稳定。A–P 分配独立稳定色相；原文与译文在原有正文颜色上混入 33% 对应色，对比度不足时向黑 / 白修正，优先保证浅 / 深主题可读。未知说话人沿用原色。历史详情与折叠屏实时译文区使用同一规则。

## 视觉与交互

- 应用对外显示名为「RC翻译魔芋」；桌面 / 系统应用列表、录音通知标题与设置页应用信息共用 `@string/app_name`。

- 页面仅显示中文标题，去除英文副标题、宣传语、重复设置说明和模型页技术装饰文案。空字幕显示“暂无字幕”，字号示例使用“字幕预览”；保留演示标识、模型状态、错误、许可和版本信息。横屏侧栏可滚动，短窗口仍能访问全部页面。

- 2026-10-23 起使用牛皮纸暖色风格，并按反馈减淡黄色：浅色背景为纯色浅奶油色 `#F6EFDF`，导航及录音控制为纯色米白 `#FCF7EB`，选中底色为淡米色 `#EEE1C4`，棕色主按钮与深棕正文；去除背景曲线、渐变和玻璃高光，不添加纸张纹理。深色主题使用暖棕底与浅米色正文。字幕继续使用高对比无框排版；面板以细边框和轻微阴影区分，开启降低透明度时移除阴影，所有面板始终不透明。浅/深/系统主题及字体缩放继续可用。

- Material 3，使用固定暖色主题，默认跟随系统暗色/浅色；优先清晰文本与低干扰操作。
- 设置的“显示”区提供“衬线字体”开关，默认开启（旧设置未保存该项时也开启），选择持久化并立即应用到全局标题、正文、字幕、按钮及弹窗。使用系统 Serif / SansSerif 字体族，不联网下载字体；具体中文字形由设备系统字体及回退决定。
- 圆角统一为小半径圆角矩形：说话人标记 4 dp，按钮 / 输入框 / 分段控件外沿 / 导航选中项 8 dp，导航与录音面板 / 菜单 12 dp，弹窗 16 dp。使用同一套 Material Shapes，不再使用 28–32 dp 大圆角或胶囊按钮；开关和滑块保留标准状态结构。正文、页标题、列表及设置内容的水平缩进统一 16 dp；底部面板与侧栏外留白 8 dp，录音面板内留白 4 dp，导航内留白 4 dp。模型与记录条目垂直留白统一 16 dp；弹窗保留 24 dp 内容留白。沿用 48 dp 触控范围与现有折叠避让。
- 按钮可触控范围不少于 48 dp，使用 Vector 图标；字体随系统缩放，处理折行和长句。
- 动画只表示真实录音/VAD/模型状态，使用 Compose 动画 API，遵守系统动画减少设置；不要让 20 ms 音频帧引发 UI 20 ms 重组。
- 适配横屏、分屏、平板和折叠屏；前台服务通知有明确停止入口。
- 错误要指出原因：麦克风拒绝、模型未安装、原生库加载失败、被其他应用占用、热降级。
- 设置页使用自动 / 省电分段控件。压力降级在 Live 页持续显示，不遮住暂停 / 停止；系统热状态、可用内存和降级语段计数显示在设置诊断区，并沿用折叠屏区域避让。进程 PSS / RSS 另由 IO worker 每 5 秒采样，不与系统可用内存混淆；不支持或失败时显示不可用。
- 最近一次生产运行的内存诊断可显式导出 JSON / CSV，格式选择弹窗沿用安全单区。打开系统 SAF 前固定本次报告对象，新录音不会更换导出目标；不是自动保存或上传。
- 启动器使用原创生成的「翻译魔芋」立体图标：魔芋主体放大至铺满圆角矩形，保留玉绿 / 珊瑚双向对话标记，使用浅暖灰自适应底色。Android 13+ 另有同步放大的主题单色层；通知继续使用独立矢量小图标。资源与生成提示见 `12_ICON.md`，实际图标轮廓随 launcher 蒙版，OEM 裁切待实机验收。

## 折叠屏与多窗口

### 2026-10-26 全流程细节审查

- 通用间距使用 4 / 8 / 12 / 16 / 24 dp；导航选中项内距为水平 8、垂直 4 dp，在保持 48 dp 触控范围的同时保留字幕阅读高度。导航、录音状态及字幕元数据的辅助文字至少 12 sp。字幕正文继续尊重用户选择的字号；字幕内部的 3 / 6 dp 紧凑节奏和随字体伸缩的说话人标记属于明确的密度设计，不套用通用控件间距。
- 200% 字体下，演示标识独立成行；说话人标记与名称作为一组、语言与时间作为另一组，空间不足时按组换行。主题与性能分段按钮保持等高。会话标题最多两行，超长省略，完整标题可在重命名输入框横向查看。
- 删除入口与确认使用危险色，始终配有删除图标或文字。模型确认说明重新下载 / 导入路径，并在占用 / 安装期间禁用确认。保留既有“两次独立左滑”防误触语义。重命名空白内容显示就地说明并禁用保存。
- 演示开关与其他开关均支持整行切换；会话锁定时显示原因。城市未变化时禁用保存，已持久化的当前城市显示确认文字；城市操作按钮可换行。字号滑块提供名称和值的可访问语义。历史列表和详情空状态分别提供说明；无诊断报告时说明不可导出的条件。
- 普通弹窗正文支持滚动，最大宽度 560 dp，左右各保留 16 dp 外边距；系统键盘出现后仍需可访问操作按钮。折叠弹窗沿用完整安全区域与 16 dp 留白，不能以普通窗口截图替代铰链验收。
- 本轮逐项分配、独立复审分数和证据缺口见 `27_UI_AUDIT.md`；仅构建 / 主机测试通过不构成 UI 满分验收。
- 按钮与面板嵌套按同心边界处理：12 dp 面板、4 dp 等距内留白、8 dp 控件圆角。录音主按钮随控制行高度伸缩，大字体下上下与右侧仍保持 4 dp；状态文字另补 4 dp 左距，与正文的 16 dp 基线对齐。录音面板左右外留白 8 dp，与底部导航边缘对齐；两块有框面板之间间隔 8 dp，上方无框字幕到控制面板仍为 4 dp，以保留阅读高度。底部导航及侧栏选中项沿用相同嵌套关系。图标按钮的按下 / 悬停反馈、城市文字按钮及滑动删除按钮显式使用 8 dp 圆角，开关和滑块保留标准结构。

使用 AndroidX WindowManager 1.5.1 的 `WindowInfoTracker` 监听实际窗口内的 `FoldingFeature`，不能仅凭屏幕宽度或设备型号判断折叠状态。

| 窗口状态 | 布局规则 |
| --- | --- |
| 外屏、小窗口、普通手机 | 单列字幕，底部录音控制与导航 |
| 展开平屏、无分隔且无遮挡的折痕 | 按当前窗口宽度布局；可用宽度至少 600 dp 时使用侧栏，Live 使用导航外的全宽字幕；其他页面在正文宽度足够时使用双栏 |
| 竖向分隔铰链 / 半折叠书本姿态 | 字幕历史在左侧，实时译文与录音控制在右侧；其他页面使用功能双栏 |
| 横向分隔铰链 / 桌面半折叠 | 上方显示字幕，下方显示录音控制与导航 |
| 双屏实体铰链 / FULL 遮挡 | 铰链及两侧至少 8 dp 留白不放正文、控件或触控目标 |
| 两侧不足以容纳双区布局 | 使用最大的完整区域，不把单个控件或正文跨铰链放置 |

- 系统铰链坐标是窗口像素；必须扣除当前布局的窗口偏移及系统安全区，不能当作 dp 使用。多铰链先分割区域，再选完整可用区域。
- 双区要求每区至少 280 dp 宽、240 dp 高；系统字体超过 130% 时提高到 320 dp / 360 dp。不满足时采用单区回退。
- Models 使用语音模型 / 翻译模型两个分区；Settings 使用显示与隐私 / 性能与诊断两个分区。小窗口按原顺序单栏滚动，大窗口两个区域独立滚动；不只把普通手机页面放在内屏一边。导航仍放在安全区域。
- Sessions 使用列表 / 详情双栏，展开时默认展示首条记录，选择项有文字语义与选中样式。收窄后保留所选详情，不跳回列表；系统返回先回列表。列表与详情采用稳定内容槽，详情按 sessionId 保存滚动状态，支持可保存状态重建。
- 无实体分隔的双栏要求扣除导航后的正文至少容纳两列 360 dp、24 dp 间距，高度至少 240 dp；字体超过 130% 时提高到两列 400 dp、高度 360 dp。实际铰链分区优先，不再对单侧强制二次切栏。大字体不足时回退单栏。
- Live 仅在真实分隔铰链的侧向双栏增加独立实时译文伴随区；无分隔的平展屏保持完整宽度字幕。历史阅读可留在左边，最新语段在右边更新，停止 / 暂停保持在下方。伴随区可滚动；横向 tabletop 保持上方阅读 / 下方控制，不在下方强塞第二份字幕。背景可以铺满，正文、滚动内容、Snackbar 与录音控件均裁切在完整区域内。
- 删除、重命名及导出选择弹窗限制在主区域内，结合自身窗口安全区和键盘高度重新测量。工具提示按照锚点所在区域定位，不覆盖铰链。
- 姿态改变保持同一内容组合位置、导航状态与字幕列表状态；列表向上阅读时不强制回到底部。音频采集由 Service 持有，不依赖布局尺寸或姿态，不因折叠创建第二份录音会话。
- 纯色背景可以铺满窗口，文字与交互必须避让；深色、降低透明度和大字体模式沿用同一套布局规则。

验收矩阵包含：外屏 / 展开 / book / tabletop / 双屏遮挡 / 旋转 / 分屏调整 / 200% 字体，检查正文及弹窗避让、会话连续性、滚动位置、键盘和系统栏。当前已有主机几何测试、Compose 姿态更新测试及截图；真机 OEM 姿态、采集连续性和键盘行为仍待验证，见 [验证记录](11_VALIDATION.md)。

用户追加的质量参照为「接近小红书的折叠屏适配程度」。对应验收方向是展开后的信息利用、列表详情协同、内外屏切换连续性、大小窗口与姿态下的控件可达、字体与键盘支持。它不等于已核实小红书各版本 / OEM 的具体布局，也不能仅凭主机双栏截图宣称达到同等成熟度。真实折叠动画、持续录音开合、IME 与 OEM launcher 仍需设备证明。

来源：[折叠感知布局](https://developer.android.com/develop/ui/compose/layouts/adaptive/foldables/make-your-app-fold-aware)、[WindowManager](https://developer.android.com/jetpack/androidx/releases/window)。

双栏与连续性依据：[Android adaptive apps](https://developer.android.com/develop/adaptive-apps/guides/get-started-with-adaptive-apps)、[列表 / 详情布局](https://developer.android.com/develop/adaptive-apps/guides/list-detail)。当前继续使用已有 WindowManager 和 Compose 测量层，不引入云端或新的 UI 框架。

## 系统整合阶段

首版先使用全屏 Live 页。系统悬浮字幕后续借 SYSTEM_ALERT_WINDOW 并单独授权；内部音频采集后续通过 MediaProjection，受播放 App 捕获策略限制，不假设能录制任意应用音频。

来源：[Compose](https://developer.android.com/develop/ui/compose)、[Material 3](https://developer.android.com/develop/ui/compose/designsystems/material3)。

实时页顶部为两个语言下拉框：第一框默认自动识别，支持中 / 英 / 日 / 韩 / 粤；第二框默认中文，支持同样五种具体语言。自动识别时显示单向箭头，具体语言组合显示双向互译图标；两个菜单相互排除另一框已选的具体语言，避免相同组合；自动识别仍只在第一框。两框具有独立无障碍标签和至少 48 dp 点击高度，平分工具栏可用宽度并允许长文本折行；文本与下拉箭头保持紧凑，并作为一组在各自区域居中。会话开始、录音、暂停、停止处理期间均锁定，已打开菜单随锁定关闭；停止后可重新选择。仅译文模式支持全部五语目标，演示仍明确标注固定数据。

## 2026-10-12 截图修订

实时顶部仅语言选择，模型数量显示在设置首项“离线模型”，演示开关移至设置，双语开关保留设置；控制条为单行。字号 8–24 sp，原文不低于 8 sp；正文减少间距和行高，保留系统字体缩放及至少 48 dp 操作目标。新记录以开始时设备本地时间和记录城市命名：`yyyy-MM-dd-HH:mm-[city]`，未设置城市明确标注，旧自定义名称保留。城市及时间在新会话开始时固定。设置可手动填写城市，也可点击“获取当地城市”，授权大致位置后通过手机定位及系统 Geocoder 尝试取得城市名；失败保留手动值，不改旧记录。系统服务可能联网，详见 ADR-0008。完整行为、旧记录兼容和翻译提速规划见 [21_TRANSLATION_SPEED_PLAN.md](21_TRANSLATION_SPEED_PLAN.md)。

效率维护后，记录列表每页50条元数据，详情每页200条字幕；翻页不会截断导出的完整会话。实时字幕显示最近500条，超过窗口时显示保留状态提示；完整记录在启用保留时写入数据库。见 `22_EFFICIENCY_MAINTENANCE.md`。


## 2026-10-26 记录滑动与设置层级

主导航仅即时字幕、对话记录、设置。离线模型为设置的头项，点入后保留导入 / 下载 / 删除 / 详情操作及返回设置入口；安装进度摘要保留在首项。运行与诊断为独立子页，返回键先回设置；子页选择支持状态恢复，折叠双区继续分别滚动并避让铰链。

记录列表保留原删除按钮及确认弹窗；第一次向左滑动至少 56 dp 只展开删除区，即使首滑很长也不删除；释放后第二次向左滑动至少 56 dp 直接删除同一条。向右滑动收起，短滑 / 取消不触发删除，展开后也可点击删除区。TalkBack 提供对应“显示删除 / 删除记录”动作。删除已选会话时回到列表，分页规则不变。


Dock 在同一窗口 / 姿态下保持一致的位置与尺寸，切换字幕 / 记录 / 设置及其子页不移动。展开平屏使用左侧固定栏：即时字幕、对话记录在上方，设置单独固定在底部；上方区域在短窗口内独立滚动，设置不随列表滚动。紧凑窗口及需要避让真实铰链的姿态沿用安全区域底部 dock，不能跨铰链强行统一为同一个物理坐标。
