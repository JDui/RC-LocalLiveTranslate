# 0.1.0-prealpha.4 — 轻量发行与模型一键下载

Android 9+ ARM64；versionCode 4。发行附件只有签名APK，不附模型。大小79,116,063 bytes（75.5 MiB），沿用项目签名，可覆盖旧公开版本。

主要变化：

- 缺模型时可一键下载固定上游权重，显示进度、支持取消/重试，仅取缺项；通过固定大小/SHA与生产导入器校验后原子安装。保留离线ZIP导入，不引入云识别/翻译或遥测。
- INTERNET仅用于主动下载，禁用明文流量；模型就绪后断网推理。完整权重约697 MiB，至少2 GiB可用空间。网络源可达性由使用环境决定；不提供后台续传。
- 包含紧凑字幕、8–24 sp字号、时间/城市记录标题、有界实时窗口、数据库分段保存与分页查询/导出。
- README重新截图：1080×2520竖屏与1800×1920接近方形展开屏，100%字体、原图完整画面；清理过时UI审查文档和截图，保留架构/许可证/发行说明。
