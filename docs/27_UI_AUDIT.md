## 执行和评分规则

主线程逐环节检查 → Luna Max 独立首轮复审 → 主线程修改 → Luna Max 修改后复审评分。任一轮存在已知缺陷或证据不足，不能为了达到目标而填写满分。整改后继续复审，只有连续两轮均为 10/10 的环节才通过。代码审查、主机渲染、模拟器操作、真机验收分别记录；不把前三者称作真机或真实模型验收。P0/P1 未关闭不可通过，P2 记录影响和安排，不作为遗漏其他问题的理由。
