# ADR-0002 — 首版按包组织，保留后续 Gradle 模块边界

日期：2026-10-09；状态：Accepted。

为先形成可编译、可验证的原生应用，0.1.0 使用一个 `:app` Gradle 模块，其内部按 `audio`、`core`、`data`、`model`、`ui` 组织。ViewModel 装配 Repository；Composable 不拥有采集任务或模型文件 IO。领域字幕协议与导出函数不依赖 Android UI。

03_ARCHITECTURE 中的多模块表仍是目标架构。接入真正 JNI 推理和多个独立 feature 后，再按依赖方向迁移为 Gradle 模块，避免首版为尚未实现的推理模块添加空工程。技术栈、完全离线约束及字幕事件身份协议不变。

本阶段不会把模型文件「已校验」误标为「推理已就绪」。演示数据是独立输入模式，与真实麦克风状态分开；任何性能及准确率声明仍需真机证据。
