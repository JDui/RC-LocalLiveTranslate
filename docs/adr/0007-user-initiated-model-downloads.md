# ADR-0007 — 用户主动下载本地模型

日期：2026-10-13；状态：实施。

用户要求发行APK不含权重，并在缺模型时提供一键下载。正式应用新增INTERNET权限，只用于用户点击模型页按钮后的HTTPS权重下载；保留ACCESS_NETWORK_STATE移除和明文流量禁用。没有云识别、云翻译、遥测、录音或字幕上传，模型准备完毕后推理仍完全本地，SAF离线导入继续可用。

下载目录固定于应用内置清单：SenseVoice来自sherpa维护者的Hugging Face固定revision，INT8权重大小及SHA与既有2024基线一致；Silero/CAM++来自登记的sherpa GitHub公开制品；Hy-MT2来自腾讯固定revision。小型manifest、LICENSE和SOURCE随APK内置，模型二进制不内置。原始文件下载时验证固定大小/SHA，再经现有生产ZIP导入器进行路径、清单、许可与文件身份验证及原子安装。此处摘要是模型安全要求，不是普通源码变动确认。

最多一个顺序下载任务，IO执行；进度200ms限频，15秒连接/10秒读取超时，最多8次HTTPS重定向，不发送账户信息。用户可取消，下一次读取检查或超时后结束；不承诺瞬时强制中断。每个模型安装后保留，失败/取消清理本轮临时文件，重试只取缺失模型，已有模型和会话租约不被覆盖。进程退出后不自动后台续传，下一次启动清理孤立临时下载。至少2GiB可用空间门禁，逐模型清理暂存降低峰值。

下载只由用户主动触发，打开APP不会自动联网。外部网络供应者可以看到请求IP及模型路径，这是下载的必要边界；音频与字幕不离机。README/许可与权限矩阵、合并Manifest和设备smoke断言同步更新，不再以无INTERNET权限作为整机隐私证据。原生推理库自身network=false的门禁保留。

公开发行只附APK，不附权重ZIP。权重许可证独立于应用和推理引擎；SenseVoice保留FunASR Model License 1.1，VAD为MIT，CAM++与Hy为Apache-2.0，不将下载能力视为商用权利声明。
