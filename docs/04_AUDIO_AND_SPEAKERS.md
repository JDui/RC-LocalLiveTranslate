# 04 — 音频、语言自动识别、实时声纹分离

## 音频前端

AudioRecord 单声道 PCM16，优先 16 kHz；设备不支持时实际采样率录入并重采样。采集按约 20–40 ms 帧进入有界缓冲区，另留最近 20–30 秒候选回看窗口（待测）。Silero VAD 保留前后语音 padding，限制超长句，避免开头被截断。维护 sampleOffset 半开区间、麦克风路由变化和暂停恢复事件。

当前实现先尝试 16 kHz，再尝试 48 / 44.1 / 32 / 8 kHz；每个未成功启动的 AudioRecord 都释放，权限撤销不作为格式失败继续重试。输入格式指 AudioRecord 提供的逻辑采样率，不声称是硬件 ADC 原生采样率。

采集线程只将原始帧 `trySend` 到容量 32 的 DSP 队列，独立 worker 使用 AndroidX Media3 1.11.1 SonicAudioProcessor 转到 16 kHz，speed / pitch 保持 1，再将不超过 320 samples 的帧非阻塞投递给推理。暂停、停止及输入切换冲刷重采样尾帧；原始帧丢失时结束旧重采样流，不跨缺口插值。时间轴由累计输入样本按有理数比例换算，避免逐帧取整漂移。候选 ASR 环目前为 10 秒；20–30 秒目标仍需内存与准确率实测后决定。

AudioRouting 回调只更新输入设备类型，采集线程检测变化后开启新的输入 epoch，第一份成功投递的输出帧带重新分段标记，连续 sampleOffset 也会冲刷 VAD。`ERROR_DEAD_OBJECT` 在任意 30 秒内最多自动重开 3 次；恢复耗时按单调时钟保留为缺失区间，不补写音频。普通暂停不计入录音样本时间。设备路由回调与硬件音频的边界精度、蓝牙采集质量及长时重采样仍须真机验收。

## SenseVoice 与自动语言

主候选 sherpa-onnx SenseVoiceSmall INT8，language=auto；中、英、日三语为产品验收范围。重要的是：它是按段语音识别，官方 Android simulated streaming 通过部分音频重识别产生临时文本，**不是原生逐 token 的零延迟 Streaming ASR**。

- 非最终 VAD 片段可按节流间隔识别为 partial；句末再识别为 final。
- 对短词/外语插入识别不确定时允许 unknown；必要时用相邻时间证据平滑 LID，而不是将 LID 硬编码为某人身份。
- 无法在短片段可靠判断语言时仅展示原文并推迟翻译；不得把 unknown 默认为 English。
- 2025-09-09 SenseVoice INT8 粤语增强模型的官方说明：**不支持标点**。分句/标点应独立处理，或对比其他经审计模型。

## SpeakerTracker（已实现，效果待校准）

sherpa-onnx 提供 speaker embedding、offline diarization 与 Android 样例，但 offline diarization **不能直接当作无限时长在线跟踪**。

1. VAD 检出语音后，累计约 0.8 秒窗口就独立投递 speaker embedding，不等待句末或 ASR；短于阈值显示 unknown，原生 extractor 未就绪时仍返回 unknown。
2. 与会话级 anchor / centroid 计算余弦相似度；候选阈值靠真机数据校准而非写死宣称正确。
3. 清晰的新声音在首份有效 evidence 即分配 speaker；不再等待第二个语段才显示。歧义仍为 unknown，后续 evidence 足够后确认、合并或拆分。
4. A -> B -> A 应复用 A；同一人从日语切到中文不得自动产生 B。
5. 可选后台滑窗 segmentation 复查句内换人点，再使用 revision 回填旧字幕。
6. 对同时讲话、很相似的声线、远距离及儿童短句标出低置信，不声称能还原每个人的重叠语音内容。

当前实现保存最近 256 份归一化 embedding，仅在声纹 worker 内存中保留；上限维度 4096，结束 worker 后清空。短于 0.8 秒、非法向量、非有限时长、重复的窗口内 segmentId 不增加确认计数。匹配 / 新声音 / 歧义阈值为 0.65 / 0.45 / 0.08。每 16 份接受证据检查一次，单次最多一项结构修订，修订后至少 64 份接受证据冷却。

2026-10-29 起，以上计数只接纳句末最终证据；提前结果改为独立 preview，不训练已有声纹。完整句末证据重新匹配，可纠正或撤回提前标签。匹配还要求 anchor 支持，质心更新另要求至少 0.75 相似度，合并保留两边原始声纹锚点。细则及局限见 [ADR-0009](adr/0009-sentence-endpoints-and-speaker-language-prior.md)。

合并要求两个已确认簇各至少 4 份近期证据，质心相似度至少 0.90，互相匹配及合并后所有证据的凝聚度至少 0.82。保留较早标签；独立会话级合并命令更新所有旧字幕及早到事件，包括超出 embedding 窗口的字幕。合并不更改文本、译文、采样时间或 ASR revision。

拆分使用固定 4 轮余弦二分，只在两个模式各至少 4 份证据、模式间相似度不高于 0.45、全部证据凝聚度至少 0.82 且匹配余量至少 0.08 时接受。原始锚点明确更接近的模式保留旧标签，否则拒绝拆分。只有仍有 embedding 的语段可重新分配；不能重建更早语段的真实身份。正式身份按会话累计最多确认 16 个，包含退休身份，永不复用；达到上限时新声音保持 unknown。未确认 preview 仅预留临时名额，撤回或淘汰即释放，不消耗正式身份额度。

算法不使用语种或文本身份特征，speaker revision 在会话内单调递增。`SPEAKER_TRACKING` 单独采样软件追踪耗时，不与 `SPEAKER` 原生抽取计时混合。上述参数是合成向量回归可验证的软件规则，不代表实际 CAM++ 的准确率。句内换人 segmentation、重叠语音恢复及真人跨语言校准仍未实现 / 验收，详见 ADR-0004。

## 过载行为

ASR 是高于字幕润色的优先任务；背景 speaker 修订最先降级。禁止无限 Channel 和录音线程等待锁。保留可观测队列长度与丢帧计数，确保错误不会被 UI 隐藏。

当前已实现热状态及内存分档：中度热状态降低临时字幕频率并暂停声纹；严重热状态或低内存只保留最终原文；临界状态停止采集并取消积压推理。暂停的可选引擎由其 worker 在当前调用结束后释放，压力持续降低 30 秒后才恢复新任务。降级期间没有翻译的旧语段标记不可用，不自动反复补译；短句及暂停声纹的语段保持 unknown。省电档位保持翻译、暂停声纹，并降低临时字幕频率。阈值是初始保护参数，不是经过 30–60 分钟真机热机验证的结论；详细规则见 10_DEVELOPMENT。

来源：[SenseVoice 预训练模型](https://k2-fsa.github.io/sherpa/onnx/sense-voice/pretrained.html)、[Android Speaker Diarization](https://k2-fsa.github.io/sherpa/onnx/speaker-diarization/android.html)。


2026-10-26 调整：声纹任务从 VAD 前端直接进入既有容量 4 队列，先尝试约 0.8 秒的语音证据，未匹配 / 未就绪时至多每秒重试，使用最近至多 2 秒音频；句末补一次完整证据。独立声纹起点不包含 ASR 的前置 padding，避免把上一段尾音用于新身份。已成功分配的 segmentId 在 worker 中有界去重，重试不增加同段确认计数；最终任务在前端结束后关闭队列，与 ASR 完成顺序解耦。省电与热降级继续暂停声纹，短段、歧义、标签上限仍返回 unknown。清晰的第一份证据立即发出带 speaker revision 的标签事件，早于文本的事件沿用 reducer / journal 的有界待回填机制。

0.8 秒是首次尝试的调度门槛，不是实测识别延迟或准确率。一个连续 VAD 语段内的换人分割仍未实现，过早有效证据可能不代表整段中的全部人；不宣称逐词分离或重叠讲话识别已完成。真人短句、相似声线和跨语种校准仍须实机验证。

## 2026-10-29 自然停顿分句与起始语言偏好

Silero 最小句末静音由 0.4 秒缩短至 0.28 秒，长语音激进检测阈值由 5 秒延至 10 秒；前端另以 160,000 samples 明确冲刷连续语音并重设 VAD 基准，限制单段音频。自然停顿优先，final ASR 立即送容量 8 的翻译队列，不等待声纹完成。仍使用实际采样区间，不按文字长度估计句子时间；犹豫可能被切开，无停顿多句仍可能同段，10 秒边界是安全回退，不是语义句末。

经同日 Astra 审核后，语言偏好改为提议和验证两步：初次 final 立即按 auto 送译；最终声纹晚到、合并 / 拆分或起始语言变化，会触发有界复核。各人独立保存最早可靠自动语言，近分候选给起始语言 0.6 的 log-score 偏好，但须通过同模型按该语言的第二次识别，验证标签、文本兼容性、内容及数字，再以更高 revision 发布文本 / 标签 / 路由。旧排队或执行中的译文不能覆盖新 revision。明显新语言或无有效分数继续采用 auto，不用文字脚本推断语言；脚本只拒绝不兼容假设，防止英文原文被改成中文后漏译。保留最近 256 段元数据及至多 8 段复核 PCM，每段最多 2 个额外假设，缺音频 / 预算时保留或恢复 auto。首次语言证据至少 1.2 秒且余量至少 0.6；均待真人校准。

同日新增连续语音的稳定标点路径：两个不同 partial 窗口给出一致句末前缀，且 tokens / timestamps 与文本可对齐时，在下一 token 起点前留一帧上下文提出切点。前端按 512-sample 网格结束首句，并从该点完整重放尾音，不压缩时间轴。中文 / 英文 / 日文真实模型 TTS 观察仍有句末标点缺失 / 误标逗号，因此无有效标点时继续自然停顿与 10 秒资源回退；此路径不保证完美语义分句。暂停 / 停止同时补齐 native VAD 残窗并裁掉补零，避免丢失不足 512 samples 的尾音。详见更新后的 ADR-0009。
